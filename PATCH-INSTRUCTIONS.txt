JARVIS-SRB Auto Update shared-pipeline and retry-choice patch

Replace these two files in your project with the matching paths from this ZIP:
- safe_repo/modules/auto_update.py
- safe_repo/core/get_func.py

No other project files are changed by this patch. Keep your existing .env, MongoDB data, and all other files.

Behaviour:
- Auto Update uses the same resilient media downloader as Save Restricted link processing.
- Video/audio/document/photo uploads reuse the normal resilient upload helpers while publishing directly to each Auto Update pair target.
- A file gets two automatic retries after its initial failure. If it still fails, the owner receives Skip File and Retry Again buttons.
- Skip advances to the next file; Retry Again resets the automatic retry counter for that file.
