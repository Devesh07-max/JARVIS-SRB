JustRunMy.App deployment

Startup command:
python -m safe_repo

Required environment variables:
BOT_TOKEN
API_ID
API_HASH
OWNER_ID
MONGO_DB
LOG_GROUP
CHANNEL_ID
CHANNEL_ID_2 (optional)

The Flask health endpoint listens on 0.0.0.0 and uses PORT (default 5000).
FFmpeg is available through imageio-ffmpeg when a system ffmpeg binary is not present.

IMPORTANT: never commit real Telegram/MongoDB credentials to this ZIP.


JARVIS SRB upgrade notes

- External media downloader: yt-dlp is installed from requirements.txt. Dockerfile installs ffmpeg for MP4 merging and MP3 extraction. Send a supported public media URL directly to the bot; Telegram message links continue through the original Telegram pipeline.
- /dlbots: requires the user's own Telegram session created with /login. It lists accessible bot chats and recent media messages only. Protected-content restrictions are not bypassed.
- FloodWait: long waits pause the current batch file and show a Resume Download button after the timer. If the process restarts during a pause, the bot reports the interrupted Telegram link instead of claiming the batch resumed.
- Forward destinations: manage saved channels under /customisations -> Forward Chat ID. Reset Customisation leaves the saved channel list and selected destination untouched.
- PayPal: configure PAYPAL_CLIENT_ID and PAYPAL_CLIENT_SECRET. Use https://api-m.sandbox.paypal.com for sandbox tests; set PAYPAL_BASE_URL=https://api-m.paypal.com for live payments. PayPal is USD-priced using the existing plan USD prices. Never commit credentials.


AUTO UPDATE FEATURE
-------------------
- Auto Update pairs and activity logs are stored in MongoDB database
  `jarvis_srb_new` (collections: `auto_update_pairs`, `auto_update_logs`).
- No new required environment variables. Optional: AUTO_UPDATE_POLL_INTERVAL
  (default 10 seconds; minimum 5).
- Users must run /login in the bot. The saved user session reads/downloads
  from the source channel. The JARVIS bot must be an administrator in each
  target channel with permission to post messages and media.
- Open /customisations -> Auto Update -> Add New Pair. Send source and target
  channel IDs separated by a space.
- A newly created or edited pair starts monitoring from the latest source
  message at setup time; it does not backfill old posts.
- Render must run one bot process/worker instance for this MongoDB deployment.
  The worker starts automatically with the bot process.
